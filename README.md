# SMP Tracker

A personal health and activity tracking application developed as part of my Python and AI learning journey.

## Overview

SMP Tracker allows users to record and review daily wellness information, including sleep duration, water intake, and steps taken.

The project includes a coaching interface that evaluates user inputs and provides feedback based on predefined conditions.

## Features

- Daily wellness data entry
- Sleep, water intake, and step tracking
- Goal prediction and feedback
- Coaching recommendations
- Session history
- Dashboard interface

## Technologies

- Python
- JavaScript
- HTML
- CSS
- Git and GitHub

## Project Structure

| File | Purpose |
|---|---|
| api.py | API functionality |
| main.py | Python application entry point |
| checkin.html / checkin.js | Daily check-in interface |
| coach.html / coach.js | Coaching and goal prediction interface |
| dashboard.html / dashboard.js | Dashboard interface |
| history.js | Session history management |
